## 安装

> 以下命令需要你自己执行：本仓库不包含安装脚本，也不会自动修改你的 profile。

**方式一：插件页安装**

1. 侧边栏 → **插件** → **添加插件**
2. 输入 `<github:user/repo 或本地路径>`
3. 按提示启用，重启 DSH，然后刷新页面
4. <如何确认装好了：界面上出现什么>

**方式二：命令行**

```powershell
# 先确认自己的 profile 名，不要照抄
$env:DSH_PROFILE

dsh plugin --profile <profile> add <github:user/repo>
```

本地开发调试：

```powershell
dsh plugin --profile <profile> add "<项目绝对路径>"
```

> 本地目录是链接安装，**不要移动或删除原目录**，否则插件随之失效。

## 写作要求

- **诚实**：没验证的写"未验证"，不写"已测试通过"。
- **具体**：不写"支持多种格式"，写"支持 Markdown 和 JSON"。
- **可执行**：每条命令能复制即用（除占位符）。
- **无隐私**：不出现真实用户名、绝对路径、真实会话 ID、任何凭据。
- **不夸大**：不写"强大""优雅""极致"这类无信息量的词。

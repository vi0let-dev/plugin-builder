# 代码审计报告模板

> 用法：复制到项目根的 `AUDIT.md`，把占位符替换为真实结论。
> 不许留空结论；不许把"未检查"写成"通过"。没有发现问题的类别也要保留一行"无"。

## 填写纪律

1. **结论必须三选一**，不能写"基本安全"。
2. **每条问题都要有位置**（`file:line`），没有位置的描述等于无法复核。
3. **"接受的风险"要写理由**，不能只写"低危"。
4. **不虚报**：没跑的扫描不写"扫描通过"；没修的项不列进"已修复"。
5. **不泄露**：报告本身不能包含被审计出的真实凭据原文——只写类型与位置，写 `<已删除>` 而不是把 Key 抄一遍。
